### 🧩 1.1 The Alphabet Code

In this system, **every letter of the alphabet becomes a power of 10**. The position of each letter in the alphabet determines its exponent.

| Letter | Position | Value |
| ------ | -------- | ----- |
| a      | 1        | 10¹   |
| b      | 2        | 10²   |
| c      | 3        | 10³   |
| d      | 4        | 10⁴   |
| e      | 5        | 10⁵   |
| ...    | ...      | ...   |
| z      | 26       | 10²⁶  |

> **Mnemonic:** _Think of “a” as the beginner (10¹) and “z” as the master (10²⁶)._

This mapping gives us a language where **letters = powers**, and **words = products** of these powers.

### ✍️ 1.2 Writing Letters as Numbers

Try converting letters to their exponential form:

- `f` = 10⁶
- `z` = 10²⁶

**Example 2:**
What is the exponential form of the word **"cab"**?

- b = 10²

- 10⁶ = **f**

### 🧮 1.3 The Rules of the Game

This system uses the **laws of exponents**.

#### ➊ Multiplication: Add the exponents

> `b × c = 10² × 10³ = 10⁵ = e`

#### ➋ Division: Subtract the exponents

> `f ÷ b = 10⁶ ÷ 10² = 10⁴ = d`

#### ➌ Exponentiation: Multiply the exponents

> `(b)² = (10²)² = 10⁴ = d`
