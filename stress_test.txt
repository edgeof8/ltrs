# Alphabet of Powers - Stress Test Script
# This script tests complex operator precedence, associativity,
# symbolic manipulation, numerical stability, and edge cases.

# --- 1. Precedence and Associativity ---
# Expected: (2*3) + 4 = 10
2*3+4
# Expected: 2 + (3*4) = 14
2+3*4
# Expected: (2*a) + b = 20 + 100 = 120
2a+b
# Expected: 2 + (a*b) = 2 + 10*100 = 1002
2+ab
# Expected: 2 * (a^3) * b = 2 * 1000 * 100 = 200000
2a^3*b
# Expected: (2*a)^(3*b) -> (20)^(300) -> Huge number, symbolic fallback
(2a)^(3b)
# Right associativity of power: 2^(3^2) = 2^9 = 512
2^3^2
# Left associativity override: (2^3)^2 = 8^2 = 64
(2^3)^2

# --- 2. Unary, Implicit, and Explicit Operator Mixing ---
# Expected: -(a^b) = -(10^100) = -Z
-a^b
# Expected: (-a)^b = (-10)^100 = 10^100 = Z (since power is even)
(-a)^b
# Expected: a^(-b) = 10^(-100)
a^-b
# Expected: -2-3 = -5
-2-3
# Expected: -2*-3 = 6
-2*-3
# Expected: 2*-a = 2 * (-10) = -20
2*-a
# Expected: 2(-a) = 2 * (-10) = -20
2(-a)
# Expected: -2a = -(2*a) = -20
-2a

# --- 3. Symbolic Exponents (Towers of Powers) ---
# Expected: a^(b^c) -> 10^(100^1000) -> Symbolic result a^(a^Z)
a^b^c
# Expected: (a^b)^c -> 10^(100*1000) = 10^100000 -> Symbolic result a^(de)
(a^b)^c
# Expected: a^(b+c) = 10^(100+1000) = 10^1100 -> Symbolic result a^(ac)
a^(b+c)
# Expected: a^b * a^c = a^(b+c) = 10^1100 -> Symbolic result a^(ac)
a^b * a^c
# Expected: 2^(a^b) + 3 -> Symbolic result
2^(a^b)+3

# --- 4. Numerical Stability and High Precision ---
# Expected: 1/3 + 1/3 + 1/3 = 1
1/3+1/3+1/3
# Expected: #e^#j*#pi -> Euler's Identity: cos(pi) + i*sin(pi) = -1
#e^(#j*#pi)
# Expected: 0.1 + 0.2 == 0.3 -> 1 (True) due to Decimal precision
0.1 + 0.2 == 0.3
# Expected: a very large number that should not overflow but be symbolic
Z^Z
# Division by zero
1/0
# Large coefficient absorption test
1000c
# Large coefficient that is NOT a power of the base
1001c

# --- 5. Complex Parenthetical Expressions ---
# Expected: 2 * (a + b*(c-d) - e/f) -> 2 * (10 + 100*(1k-10k) - 100k/1m) = 2*(10+100*(-9k)-0.1) = 2*(10-900k-0.1) = 2*(-899990.1) = -1799980.2
2(a+b(c-d)-e/f)
# Expected: ((a+b)^2 - (c-d)^2) / (a+b-(c-d)) -> (a+b+c-d) -> 10+100+1k-10k = -8890
((a+b)^2-(c-d)^2)/(a+b-(c-d))

# --- 6. Variable Assignment and Usage ---
# Assign a variable
$x = a+b
# Use the variable
$x * c
# Reassign the variable
$x = Z
# Use it again
$x / b
# Chained assignment
$y = $z = #pi
# Use chained variables
$y + $z - 2#pi
# Assign result of complex expression to var
$res = (a^b^c)/(a^b*a^c)
# Use the result (should be a^(b^c - (b+c)))
$res

# --- 7. Edge Cases and Constants ---
# Operations with zero
a*0
a+0
a^0
0/a
# Operations with one
a*1
a/1
a^1
1^a
# Word calculation and comparison
cat == x
dog == l
# Test all constants
#pi + #e + #phi + #tau + #sqrt2 + #j + #sqrt3 + #ln2
