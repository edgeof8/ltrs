Cells

Each cell keeps the source on the first line and the answer below it. Huge results stay inside the cell (ellipsis); the strip under the formula bar shows the full value, selectable to copy.

Other cells read this one as $A1. Named variables still work: $x = a*b. Adjacent letters add (ba is 110). Multiply with *.

Shortcuts

  • Enter evaluate, move down · Shift+Enter new line
  • Tab evaluate, move right
  • F2 edit · Esc cancel
  • Delete clear · Ctrl+Z undo
  • Ctrl+C / V copy source / paste
  • Ctrl+S save · Ctrl+O open
  • Drag a column or row header edge to resize. W / H set the selected column and row. Double-click a handle to reset.

Commands

Type in a cell: /help, /vars, /base, /setbase 2, /letters, /constants.
