Cells

Each cell keeps the source on the first line and the answer below it. Huge results stay inside the cell (ellipsis); the strip under the formula bar shows the full value, selectable to copy.

Other cells read this one as $A1. A range $A1:$C1 sums that rectangle (empty cells are 0). Named variables still work: $x = a*b. Adjacent letters add (ba is 110). Multiply with *.

Shortcuts

  • Enter evaluate, move down · Shift+Enter new line
  • Tab evaluate, move right · F2 edit · Esc collapse / cancel
  • Delete clear the selection · Ctrl+Z undo · Ctrl+A all
  • Ctrl+C / V copy source / paste (refs shift)
  • Ctrl+S save · Ctrl+O open
  • While editing, click a cell to insert $B2; Shift+click extends that to a range $B2:$D4
  • Drag across cells to select. Click a header for the whole row or column. Drag the blue square to fill; Ctrl+D / R fill down / right.
  • Drag a column or row header edge to resize. W / H set the selected column and row.

Commands

Type in a cell: /help, /vars, /base, /setbase 2, /letters, /constants.
