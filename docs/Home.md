# Welcome to the Alphabet of Powers (AoP) Wiki!

This wiki provides comprehensive documentation for the "Alphabet of Powers" (`ltrs`) Python library and command-line tool.

## What is the Alphabet of Powers?

The Alphabet of Powers (AoP) is a mathematical system where letters of the alphabet correspond to powers of a given base (default is 10). For example, with base 10:

- `a` = 10<sup>1</sup>
- `b` = 10<sup>2</sup>
- ...
- `z` = 10<sup>26</sup>

The `ltrs` tool allows you to:

- Evaluate complex mathematical expressions using AoP notation.
- Perform calculations involving standard arithmetic operators (`+`, `-`, `*`, `/`, `^`).
- Utilize mathematical functions (`sqrt`, `log`, `ln`, `log2`, `sin`, `cos`, `tan`).
- Work with different numerical bases.
- Assign expressions to variables for later use.
- Visualize expressions with a built-in graphing feature.
