# hardware.py (CPU Simulation)

Simulates CPU arithmetic operations and benchmarks multiplication algorithms.

## Key Classes

### `CPU`

Main class for multiplication algorithm benchmarking.

#### Key Methods

- `intelligent_multiply(n1, n2)`: Selects optimal algorithm
- `_multiply_schoolbook(n1, n2)`: Traditional iterative method
- `_multiply_aop_optimized(n1, n2)`: Sparse addition optimization
- `_multiply_karatsuba(n1, n2)`: Recursive divide-and-conquer
- `_multiply_lookup_table(n1, n2)`: Uses precomputed table

### Core Primitives

- `number_to_bitlist(n)`: Convert int to bit list (LSB first)
